⚡ Ejercicio 1 — Fuente 12V

Lista de Componentes

R1 = 330 Ω
R2 = 1 kΩ = 1000 Ω
R3 = 2.2 Ω ← valor corregido
R4 = 4.7 kΩ = 4700 Ω
R5 = 680 Ω

Topología

R1 en serie con la fuente.
R2, R3, R4, R5 en paralelo entre sí.
Estructura: Fuente → R1 → [R2 ‖ R3 ‖ R4 ‖ R5]

Procedimiento de Cálculo

PASO 1: Resistencia equivalente del bloque paralelo ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 1/Rp = 1/R2 + 1/R3 + 1/R4 + 1/R5 1/Rp = 1/1000 + 1/2.2 + 1/4700 + 1/680 1/Rp = 0.001 + 0.4545 + 0.000213 + 0.001471 1/Rp = 0.4572 Ω⁻¹ Rp = 1 / 0.4572 = 2.187 Ω ⚡ R3 (2.2Ω) DOMINA el paralelo porque es 1000x menor que las demás resistencias. Casi toda la corriente fluye por esta rama. PASO 2: Resistencia equivalente total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ REQ = R1 + Rp = 330 + 2.187 = 332.19 Ω PASO 3: Corriente total (Ley de Ohm) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IT = V / REQ = 12 / 332.19 = 0.03612 A = 36.12 mA PASO 4: Voltajes en cada bloque ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ VR1 = IT × R1 = 0.03612 × 330 = 11.92 V Vparalelo = V - VR1 = 12 - 11.92 = 0.08 V ⚡ R1 consume casi todo el voltaje (99.3%) porque es mucho mayor que el bloque paralelo. PASO 5: Corrientes por cada rama paralela ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IR2 = Vparalelo / R2 = 0.08 / 1000 = 0.08 mA IR3 = Vparalelo / R3 = 0.08 / 2.2 = 36.36 mA ← 99.9% IR4 = Vparalelo / R4 = 0.08 / 4700 = 0.017 mA IR5 = Vparalelo / R5 = 0.08 / 680 = 0.118 mA Verificación: 0.08 + 36.36 + 0.017 + 0.118 ≈ 36.12 mA ✓ PASO 6: Potencia total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PT = V × IT = 12 × 0.03612 = 0.433 W

⚡ Ejercicio 2 — Fuente 15V

Lista de Componentes

R1 = 470 Ω
R2 = 1.2 kΩ = 1200 Ω
R3 = 3.3 kΩ = 3300 Ω
R4 = 1 kΩ = 1000 Ω
R5 = 2.2 kΩ = 2200 Ω
R6 = 820 Ω

Topología

R1 en serie con la fuente.
R2 en paralelo con el resto.
Resto: R4 en serie con [R3 ‖ (R5 + R6)]

Procedimiento de Cálculo

PASO 1: Serie R5 + R6 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R56 = R5 + R6 = 2200 + 820 = 3020 Ω PASO 2: Paralelo R3 ‖ R56 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R3‖56 = (R3 × R56) / (R3 + R56) R3‖56 = (3300 × 3020) / (3300 + 3020) = 9966000 / 6320 R3‖56 = 1576.9 Ω PASO 3: Serie R4 + (R3‖56) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R4_3_56 = R4 + R3‖56 = 1000 + 1576.9 = 2576.9 Ω PASO 4: Paralelo R2 ‖ R4_3_56 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R2‖resto = (R2 × R4_3_56) / (R2 + R4_3_56) R2‖resto = (1200 × 2576.9) / (1200 + 2576.9) = 3092280 / 3776.9 R2‖resto = 818.7 Ω PASO 5: Serie R1 + (R2‖resto) = REQ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ REQ = R1 + R2‖resto = 470 + 818.7 = 1288.7 Ω PASO 6: Corriente total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IT = V / REQ = 15 / 1288.7 = 0.01164 A = 11.64 mA PASO 7: Voltajes ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ VR1 = IT × R1 = 0.01164 × 470 = 5.47 V Vparalelo = V - VR1 = 15 - 5.47 = 9.53 V PASO 8: Corrientes ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IR2 = Vparalelo / R2 = 9.53 / 1200 = 7.94 mA Iresto = Vparalelo / R4_3_56 = 9.53 / 2576.9 = 3.70 mA VR4 = Iresto × R4 = 0.00370 × 1000 = 3.70 V Vparalelo_interno = 9.53 - 3.70 = 5.83 V IR3 = 5.83 / 3300 = 1.77 mA IR5 = IR6 = 5.83 / 3020 = 1.93 mA VR5 = 0.00193 × 2200 = 4.25 V VR6 = 0.00193 × 820 = 1.58 V Verificación VR5 + VR6 = 4.25 + 1.58 = 5.83 V ✓ PASO 9: Potencia total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PT = V × IT = 15 × 0.01164 = 0.175 W

⚡ Ejercicio 3 — Fuente 9V

Lista de Componentes

R1 = 220 Ω
R2 = 470 Ω
R3 = 1 kΩ = 1000 Ω
R4 = 1.5 kΩ = 1500 Ω
R5 = 2.7 kΩ = 2700 Ω
R6 = 390 Ω

Topología

R1 en serie con la fuente.
R2, R3, R4, R5, R6 en paralelo entre sí.
Estructura: Fuente → R1 → [R2 ‖ R3 ‖ R4 ‖ R5 ‖ R6]

Procedimiento de Cálculo

PASO 1: Resistencia equivalente del bloque paralelo (5 ramas) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 1/Rp = 1/R2 + 1/R3 + 1/R4 + 1/R5 + 1/R6 1/Rp = 1/470 + 1/1000 + 1/1500 + 1/2700 + 1/390 1/Rp = 0.002128 + 0.001 + 0.000667 + 0.000370 + 0.002564 1/Rp = 0.006729 Ω⁻¹ Rp = 1 / 0.006729 = 148.6 Ω ⚡ R6 (390Ω) y R2 (470Ω) dominan porque son las menores. PASO 2: Resistencia equivalente total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ REQ = R1 + Rp = 220 + 148.6 = 368.6 Ω PASO 3: Corriente total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IT = V / REQ = 9 / 368.6 = 0.02442 A = 24.42 mA PASO 4: Voltajes ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ VR1 = IT × R1 = 0.02442 × 220 = 5.37 V Vparalelo = V - VR1 = 9 - 5.37 = 3.63 V PASO 5: Corrientes por cada rama ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IR2 = 3.63 / 470 = 7.72 mA IR3 = 3.63 / 1000 = 3.63 mA IR4 = 3.63 / 1500 = 2.42 mA IR5 = 3.63 / 2700 = 1.34 mA IR6 = 3.63 / 390 = 9.31 mA ← mayor corriente Verificación: 7.72+3.63+2.42+1.34+9.31 = 24.42 mA ✓ PASO 6: Potencia total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PT = V × IT = 9 × 0.02442 = 0.220 W
