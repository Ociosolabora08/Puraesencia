⚡ Ejercicio 1 — Fuente 12V

Lista de Componentes

R1 = 220 Ω
R2 = 330 Ω
R3 = 470 Ω
R4 = 680 Ω
R5 = 1 kΩ = 1000 Ω

Topología

R1 en serie.
R2 y R3 en paralelo.
R4 y R5 en serie.
Estructura: R1 + (R2‖R3) + R4 + R5
PASO 1: Paralelo R2 ‖ R3 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R2‖R3 = (R2×R3)/(R2+R3) = (330×470)/(330+470) = 155100/800 = 193.875 Ω PASO 2: Serie R1 + (R2‖R3) + R4 + R5 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ REQ = 220 + 193.875 + 680 + 1000 = 2093.875 Ω ≈ 2094 Ω PASO 3: Corriente Total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IT = V/REQ = 12/2093.875 = 5.731 mA PASO 4: Voltajes (Ley de Ohm) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ VR1 = IT×R1 = 5.731mA × 220Ω = 1.261 V VR2 = VR3 = IT×R2‖R3 = 5.731mA × 193.875Ω = 1.111 V VR4 = IT×R4 = 5.731mA × 680Ω = 3.897 V VR5 = IT×R5 = 5.731mA × 1000Ω = 5.731 V Verificación: 1.261 + 1.111 + 3.897 + 5.731 = 12.000 V ✓ PASO 5: Corrientes ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IR1 = IR4 = IR5 = IT = 5.731 mA IR2 = VR2/R2 = 1.111/330 = 3.367 mA IR3 = VR3/R3 = 1.111/470 = 2.364 mA Verificación: 3.367 + 2.364 = 5.731 mA ✓ PASO 6: Potencia Total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PT = V×IT = 12×5.731mA = 68.77 mW

Lista de Componentes

R2 = 470 Ω
R3 = 680 Ω
R4 = 1 kΩ = 1000 Ω
R5 = 1.5 kΩ = 1500 Ω
R6 = 2.2 kΩ = 2200 Ω

Topología

R1 en serie.
Rama sup: R2+R3 (serie).
Rama inf: R4+R5 (serie).
R6 en serie al final.
Estructura: R1 + [(R2+R3)‖(R4+R5)] + R6
PASO 1: Series internas ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R23 = R2+R3 = 470+680 = 1150 Ω R45 = R4+R5 = 1000+1500 = 2500 Ω PASO 2: Paralelo R23 ‖ R45 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ R23‖45 = (1150×2500)/(1150+2500) = 2875000/3650 = 787.67 Ω PASO 3: Serie R1 + paralelo + R6 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ REQ = 330 + 787.67 + 2200 = 3317.67 Ω ≈ 3318 Ω PASO 4: Corriente Total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IT = V/REQ = 15/3317.67 = 4.521 mA PASO 5: Voltajes ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ VR1 = 4.521mA × 330 = 1.492 V Vparalelo = 4.521mA × 787.67 = 3.561 V VR6 = 4.521mA × 2200 = 9.947 V Verificación: 1.492 + 3.561 + 9.947 = 15.000 V ✓ PASO 6: Corrientes ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IR1 = IR6 = IT = 4.521 mA IR2 = IR3 = Vparalelo/R23 = 3.561/1150 = 3.097 mA IR4 = IR5 = Vparalelo/R45 = 3.561/2500 = 1.424 mA Verificación: 3.097 + 1.424 = 4.521 mA ✓ PASO 7: Potencia Total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PT = V×IT = 15×4.521mA = 67.82 mW

⚡ Ejercicio 5 — Fuente 24V (Puente)

Lista de Componentes

R1 = 330 Ω
R2 = 470 Ω
R3 = 680 Ω
R4 = 1 kΩ = 1000 Ω
R5 = 1.5 kΩ = 1500 Ω
R6 = 2.2 kΩ = 2200 Ω

Topología

R1 en serie con la fuente.
Puente (bridge) formado por R2, R3, R4, R5, R6.
R4 conecta los puntos medios de las ramas (puente).
Requiere transformación Δ-Y para resolver.
PASO 1: Identificar triángulo para transformación Δ-Y ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Triángulo: R3 (680Ω), R4 (1000Ω), R5 (1500Ω) Suma = 680 + 1000 + 1500 = 3180 Ω PASO 2: Transformación Δ → Y ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Ra = (R3×R4)/Suma = (680×1000)/3180 = 213.84 Ω Rb = (R3×R5)/Suma = (680×1500)/3180 = 320.75 Ω Rc = (R4×R5)/Suma = (1000×1500)/3180 = 471.70 Ω PASO 3: Circuito equivalente en Y ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Nueva rama superior: Ra + R2 = 213.84 + 470 = 683.84 Ω Nueva rama inferior: Rb + R6 = 320.75 + 2200 = 2520.75 Ω Rc queda en serie con la combinación paralela PASO 4: Paralelo de las dos ramas ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ Rramas = (683.84 × 2520.75) / (683.84 + 2520.75) = 1723446/3204.59 = 537.80 Ω PASO 5: REQ total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ REQ = R1 + Rramas + Rc = 330 + 537.80 + 471.70 = 1339.50 Ω PASO 6: Corriente Total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ IT = 24/1339.50 = 17.92 mA PASO 7: Voltajes principales ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ VR1 = 17.92mA × 330 = 5.913 V Vramas = 17.92mA × 537.80 = 9.635 V VRc = 17.92mA × 471.70 = 8.451 V Verificación: 5.913 + 9.635 + 8.451 = 24.000 V ✓ PASO 8: Potencia Total ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ PT = 24 × 17.92mA = 430.0 mW
